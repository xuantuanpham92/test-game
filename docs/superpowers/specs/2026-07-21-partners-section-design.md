# 结果页合作伙伴栏目设计

## 目标

在结果分析页底部的团队介绍与联系方式之间，增加一个不依赖外部数据的合作伙伴展示区。首版使用精美占位内容，为未来替换真实伙伴名称、Logo 与链接保留清晰入口。

## 页面位置与内容

栏目位于 `SloganBanner`、团队介绍之后，`ContactSection` 之前。它不改变报告、二维码或人格卡片的现有功能。

- 顶部文案：`合作伙伴`
- 主标题：`与优秀伙伴，共赴成长`
- 辅助文案：表达扶摇与教育创新伙伴协作、为学生创造学习体验的定位。
- 三张占位伙伴卡：`教育创新伙伴`、`学习成长伙伴`、`技术共创伙伴`。

## 视觉与交互

采用“星轨共创”风格：深靛蓝到紫色的渐变背景，叠加低透明度的径向光晕、星点与弧形轨道装饰。内容卡使用半透明白色玻璃质感、细描边和轻阴影，延续结果页的紫粉品牌色。

当栏目滚入视口时，容器与三张伙伴卡按现有 Framer Motion 动画规范渐入上移；桌面端三列排布，移动端单列排布。卡片仅做轻微悬浮效果，不设置链接或点击行为，避免占位内容造成无效跳转。

## 实现边界

- 在 `app/result/[id]/page.tsx` 内新增独立的 `PartnersSection` 子组件，并在主页面中插入。
- 使用现有 Tailwind 工具类、`motion`、`fadeUp` 与 `stagger`，不引入依赖、图片资源或后端接口。
- 使用内联 SVG 作为抽象 Logo 占位，保证首屏之外不新增网络请求，并可访问地标记为装饰元素。

## 验收标准

1. 结果页底部按既定顺序显示合作伙伴栏目。
2. 大屏显示三张并列的伙伴卡，窄屏显示单列卡片。
3. 栏目与既有渐变、圆角、动画保持一致，且不影响二维码和人格卡片。
4. `npm run typecheck` 与 `npm run build` 均通过。
